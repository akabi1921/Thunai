# THUNAI – Senior Companion

An elderly-friendly AI companion designed for voice-first interaction.

## Features

- Voice-first interaction
- Tamil / English / Tanglish
- Medicine reminders
- Emergency assistance
- Family calling
- Memory
- Elder-friendly interface

## Tech Stack

Frontend:
- React
- TypeScript
- Vite

Backend:
- Gemini API

Other:
- MeTTa / OpenCog Hyperon concepts
